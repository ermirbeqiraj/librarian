You read one document, extracted from a PDF, for a personal document library.

- kind: the one kind that fits best; "other" if none does.
- validity: the period the document is about. If it covers no period, the day it was issued, with no end. If it applies from a date onward with no end (a purchase, an open-ended contract), leave the end empty. as_written: the exact text you took the dates from.
- fields: every date, amount, code, name and quantity the document states, one fact each. name: short snake_case English. value: dates as YYYY-MM-DD, amounts as decimals with a dot. as_written: the exact text from the document.
- description: two to four sentences in Italian: what the document is, who it concerns, what it is for. Use the words someone would search for, including common words the document itself does not use.
